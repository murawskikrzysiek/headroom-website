Privacy Policy

Last updated: October 2026

Overview

Specula is a local macOS application. It does not transmit, upload or share any audio, file content or analysis results. All processing happens on the Mac. There is no telemetry and no analytics.

Audio file access

Specula opens the audio files you choose: through the file picker, drag and drop, the Finder's Open With and Services, or Check a Folder, which reads every audio file in the folder you choose, and its subfolders on request. An open file is held in memory for analysis and released when Specula quits or another file opens.

What Specula writes on your Mac

Files you ask for go where you choose: Save and Save As, the export sheet's reports (PDF, HTML and JSON), chapters CSV, edited audio and compare residual, Render to File, Split to Mono Files, the Signal Generator's files and Save Take As. Check a Folder writes its reports and CSV into a new folder beside the checked one by default, and the Finder's Get Report service saves its PDF beside the source file, or in your Downloads folder.

Corrected speech regions are saved beside the audio file they belong to, as a .dlg.json file, so they come back when the file opens again.

Working files: the edit history keeps each step's audio in the system's temporary folder while Specula runs, and the codec check keeps its AAC encode there; both are removed at the next launch once that run has ended.

In Specula's folder in your Library (Application Support): the recorded takes, kept for seven days; the chapters of files you worked on, for Recall; the last plugin chain, for Restore Last Plugin Chain; and the raw PCM presets.

Microphone and the Record task

The Record task uses your input device only while it is open, after macOS grants microphone permission through the standard system prompt. Armed, it meters the input and checks the room; it writes audio to disk only while a take records. Takes stream to Specula's takes folder in your Library and are kept there for seven days, and Save Take As… writes a take only to the location you choose. No recorded audio is ever transmitted.

Speech detection, music analysis and the codec check

Specula's speech detection runs entirely on your Mac, using the open-source Silero VAD model via the FluidAudio library, both inside the app. On macOS 27, the key, tempo, sections and stems of a song come from Apple's on-device music analysis, which runs on the Mac. The codec check encodes the file as AAC with the encoder built into macOS, on the Mac. No audio, and no information about your files, is sent anywhere by any of them.

Preferences and settings

Your settings (the five Settings tabs, the delivery category and targets, each task's views, the inspector's groups and the export sheet's choices for each delivery category) and the list of recent files, with each one's length, format and last delivery category, are stored locally on your Mac in standard macOS preferences and are never transmitted.

License activation and validation

When you activate a license, or when Specula validates it on launch, the app contacts Lemon Squeezy's licensing API at api.lemonsqueezy.com. The only data sent is your license key and a per-device instance ID generated for the activation. No audio, no file contents, and no personal data are transmitted. Your audio never leaves your Mac. During the trial, before any license is entered, the app makes no such calls.

Auto-update checks

Specula uses Sparkle for automatic updates. Sparkle periodically fetches the appcast feed at https://headroomstudio.dev/specula/appcast.xml to check for new versions. This request carries only the standard details of an HTTPS request; no system profile data is sent. Update compatibility is worked out on your Mac, from the minimum system version listed in the appcast. Settings › General › Updates turns the automatic checks off.

Purchases

When you purchase Specula, payment is processed by an external payment provider. That provider's privacy policy applies to the transaction. Headroom does not receive or store your payment details.

Contact

Questions about this policy: hello@headroomstudio.dev. Help › Send Feedback in the app opens an email to the same address in your mail app; Specula itself sends nothing.
