# /assets/screens/

Unlisted screenshot assets for forum posts (Gearspace, KVR, VI-Control, etc.)
and other one-off hotlinking.

- **Public but unlisted.** GitHub Pages serves everything, so these load fine in
  `[IMG]` tags. They are *not* linked from any page or the sitemap, and
  `robots.txt` has `Disallow: /assets/screens/` so search engines skip them.
  This is "unlisted," not access-controlled — anyone with the direct URL can view.
- **URL pattern:** `https://headroomstudio.dev/assets/screens/<filename>.png`
- Drop PNG/JPG files here, commit, push. Live ~1–2 min after push.
