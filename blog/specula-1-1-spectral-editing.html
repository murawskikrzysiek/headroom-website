Specula 1.1: spectral editing, fix what you measure

Four new surfaces: spectral repair on the same spectrogram you diagnose on, recording through the analyzer's meters, an Audio Unit chain in Edit mode, and a test-signal generator.

Krzysiek 29 July 2026 5 min read

Specula 1.1 is out, with four new surfaces. The one to start with is spectral editing. Specula has always been the app you open to see what is wrong with a file, and in 1.1 you fix it on the same spectrogram, without a round-trip to a separate restoration app.

Spectral editing (⌘5)

Spectral mode turns the main canvas into a full-resolution, zoomable spectrogram, the same view you already read to find a problem. A hum sits as a steady horizontal line, a cough or a chair squeak as a vertical smear, a phone buzz as a stack of harmonics. Select it directly: a rectangle for a clean time-frequency box, a lasso for a freehand shape, a brush to paint over something that drifts, or a wand that grabs the connected shape from a single click.

Then choose what happens to the selection. Attenuate turns it down and leaves the rest of the sound intact. Erase takes it down to the surrounding noise floor. Repair bridges across it from the clean audio on both sides, so a click or a dropped pen is filled in rather than left as a hole. Solo plays only what you selected and Result plays the span with the edit applied, so you audition the fix before you commit, and every edit is a single Undo on the same stack as the rest of Edit mode.

It works on any channel count, per channel above stereo. A squeak in the left surround of a 5.1 bed comes out of Ls alone, the other five untouched. All of it is non-destructive and saves to a new file, and because it happens on the analysis surface you are working next to the meters that flagged the problem in the first place. This is the repair you would normally export to a dedicated restoration tool to do. In 1.1 it is one selection inside Specula.

Record mode (⌘6)

Record mode records from any input device straight onto the analysis surface, and it is the only mode that works with nothing loaded. The meters run the whole time, momentary loudness to BS.1770, true peak, and per-channel level, live while armed and while rolling. Armed but not yet rolling it reads the noise floor, which is the ACX room-tone check, run before the take: you confirm the floor sits under -60 dB RMS while there is still time to fix the room.

A take lands as New (it becomes the loaded file), Append (it continues from the end, for pickups onto an hour-long episode), Insert (it drops in at the playhead and pushes the rest later), or Punch (it records over existing audio, and with a selection it replaces it, so you re-read a flubbed word and the file closes around it). Every join is an adjustable equal-power crossfade and a single Undo, To Compare sends a finished take to a Compare slot for a level-matched A/B, and recording streams to disk, so take length is bounded by the drive, not memory.

An Audio Unit chain in Edit mode

Edit mode now hosts any AU effect installed on the Mac, chained in order and tuned by ear while the file plays. The analysis tap sits after the chain, so every live meter (LUFS, true peak, FFT, spectrogram, phase) shows the processed sound as you turn knobs. Render bakes the chain in through fresh, latency-compensated instances as an ordinary undoable edit, and Render to Compare Slot loads the processed version next to the original to measure the difference. Plugins run out of process by default, so a third-party crash can't take the app down.

The Signal Generator (⌘G)

The generator builds test signals from scratch: band-limited sine, square, sawtooth, and triangle tones, white, pink, and brown noise, a single impulse, and linear or log sweeps. Sources stack when they overlap and sequence when they follow one another, per channel, and the result writes to WAV, AIFF, or CAF with a live waveform and spectrum preview. The same generator is on the command line as specula generate for scripted test-file batches.

Also in 1.1

  • The left info panel collapses (⌘I), so the analysis views get the full window width.
  • A long-file performance batch: hours-long files load without gigabytes of temporary memory, waveform zoom and pan stay smooth at every level, and whole-file loudness measurement no longer slows quadratically with length.
  • Loudness-accuracy fixes, including K-weighting that now matches the ITU-R BS.1770-4 coefficients exactly (expect readings about 0.04 LU higher than 1.0) and LRA that excludes ramp-up windows.
  • The app now asks before quitting or opening a file over unsaved work.
