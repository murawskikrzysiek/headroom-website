More than one number

A delivery spec is a loudness window, a true-peak ceiling, and sometimes a short-term cap or a noise-floor limit.

Miss any one and the file bounces. EBU R128 S1 caps max short-term. Netflix measures loudness over dialogue, not the whole programme. A true peak that reads fine on the samples can go over once the peaks between them are counted. When a file opens, Specula measures the full-programme integrated loudness and the dialogue-gated loudness, the 4× oversampled true peak, max short-term and the noise floor in one pass, checks each against every checked spec, and names the criterion that fails and by how much.

Check every spec at once

Deliver to the category, read the card, find the breaches, fix, export.

1 · Deliver to Film and TV or Broadcast
Deliver to, over the delivery card, sets what the file is judged against: Film and TV (Netflix, Prime Video, Apple TV+, Disney+, Max) or Broadcast (EBU R128, its live and S1 short-form variants, ATSC A/85, ARIB TR-B32, OP-59), with up to four specs checked and one primary, the spec the verdict leads with. Its picker opens from the chip or with ⇧⌘D. The sidebar shows the rows that fit: the Speech group appears when the file holds speech or the primary spec judges dialogue.
2 · Read the verdicts
The card judges the whole file as soon as it has loaded, with no pass to run. The primary spec's verdict is a sentence that names the criterion: "Fails Netflix on dialogue loudness: −29.2 LKFS, 2.2 LU below −27 ±2.", or "Fails EBU R128 S1 (EU, short-form) on max short-term: −15.0 LUFS, over its −18 LUFS ceiling." The other checked specs follow, each with its own short verdict, and the readings take one set of colours, red where a spec fails. A file with no speech reads "No reading for Netflix: no speech was found." ⌘Return on a selection fills a Selection card under the delivery card; the verdicts keep judging the whole file.
3 · Find the breaches
Set the M, ST and TP fields under the loudness graph to the spec's ceilings, and every 100 ms block over one is shaded on the waveform, with a count beside each field. The fields show LUFS and dBTP, start empty, and their tooltips name the primary spec's own limit, such as Netflix's −2 dBTP ceiling. More below.
4 · Fix
The primary spec's fixes are buttons that say what they do, Normalize dialogue to −27 LKFS and Limit peaks to −2.0 dBTP, and every other checked spec has a Fix menu with its own. Each opens the Edit task (⌘2) with the panel filled in, and appears only where it changes something. Max short-term and the noise floor have no fix. Every edit is listed in the Edit task's History and undoable, and the file is measured again in the background, so the card judges the edited file.
5 · Export the receipt
File › Export… (⌘E) writes the PDF, HTML and JSON reports into one folder; ⇧⌘E and ⌥⌘E open the sheet with the JSON or the PDF ticked, and what the reports include is remembered for each category. The PDF and HTML report open with the category and its specs, "Judged against: Netflix (primary), Prime Video, Apple TV+, Max", print each spec's verdict with the failing value (Not compliant · S↑ (−15.0 LUFS)) and say what speech was measured with. The JSON carries a delivery block and a verdict per target in loudnessTargets.targets[] (status, actualLUFS, the reason and the limit), so a delivery pipeline can branch on pass or fail. Right after an edit, Export waits until the file has been measured.
6 · A season at a time
File › Check a Folder… checks every audio file in a folder against Deliver to: a row per file with its verdict, integrated loudness, true peak, LRA and Speech %, a report per file and a CSV of the rows, written into a new folder beside the checked one, never into it. Batch and automation →

From verdict to location

A maximum says the master breached, and by how much. The marks say which second of forty minutes.

A QC note says "too loud". The marks say where: 2:14, 7:48, 31:02, and on which meter.

Max momentary, max short-term and max true peak settle whether the file ships, not which moment to touch. With the spec's ceilings set in the fields under the loudness graph, every 100 ms block that crosses one is shaded along the waveform, so each overshoot is a place to click to.

Three ceilings on three time scales, each catching a failure the others miss:

Momentary · 400 ms
The fast transient a slow meter sleeps through: a snare crack, a slammed door, a plosive, a music sting. The M threshold shades every block over it.
Short-term · 3 s
The sustained stretch that rides too hot: a shouted line, a loud chorus, a music bed climbing under dialogue. EBU R128 S1 caps it at −18 LUFS for short-form; the ST threshold marks every breaching span.
True peak · inter-sample
The clip a sample meter never sees: peaks that surface only once the signal is reconstructed between samples. The TP threshold, set to the spec's ceiling, flags every block whose 4× oversampled peak goes over.

Each threshold shades in its own colour and layers over the others, so where two breaches overlap both show, and each field carries its count. The marks cover the whole file as soon as it has been measured. Above the waveform, the loudness graph plots momentary and short-term against the same thresholds, so each breach shows how far over it goes, not only that it crossed.

That is the distance between a QC report and a fix: the one shouted line to ride, the one transient to cap, while the rest of a nearly-right master stays as it is.

The specs

Film and TV and Broadcast are the hard pass or fail. Film and TV judges dialogue loudness in the −27 LKFS window that Netflix, Prime Video, Apple TV+, Disney+ and Max share, with a −2 dBTP ceiling. Broadcast judges EBU R128, its live variant and R128 S1 short-form (which adds the max short-term ceiling), ATSC A/85 (the CALM Act), ARIB TR-B32 and OP-59. Each spec carries its own reference, tolerance and true-peak ceiling; every number is in the user guide.

Music streaming deals in gains: each platform's verdict says what it does to the file (mastering). Podcast judges Apple Podcasts and Spotify (podcast), and Audiobook leads with ACX, judged in ACX's own words (audiobook).

Dialogue-gated specs read the speech-gated path. Netflix and its peers, ATSC A/85 and the podcast targets measure loudness over speech only, found by the Silero neural speech detector when the file opens, so room tone and music beds do not move the verdict. The picker lists them as "dialogue −27 ±2 LKFS", and the card's headline is the dialogue loudness. Where the detection is wrong, the Speech task (⌘5) corrects the regions by hand, and the file is measured again, so the card, the fixes and the reports follow the corrections.

A spec of your own joins its category as a custom target: a reference level, a tolerance, a true-peak ceiling, and an integrated, dialogue-gated or RMS measurement.
