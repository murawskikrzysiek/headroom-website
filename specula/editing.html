When a DAW is too much

The fix is thirty seconds of work. Opening a DAW to do it is not.

A few seconds of room tone off the head, a fade on the tail, a normalize to the LUFS target the delivery asks for: through a DAW, each means a project, an import, a bounce and a settings dialog. Done by hand on the master, there is nothing to fall back to if the gain is wrong.

The Edit task does the small jobs where the file already is. Every edit is undoable from its history, and Save As writes a new file, so the source stays as it was on disk. With Settings › Editing and plugins › Allow Save to overwrite the original file, Save (⌘S) writes over a working file instead, keeping its format, bit depth and channel layout, and swaps the new data in only once it is fully written.

Three steps, no project

Open the task, run the operation, save.

1 · Open the Edit task
⌘2, or Edit in the top bar. The task bar holds Cut, Trim, Fade In, Fade Out and Gain, a Loudness menu (Normalize…, Limit True Peak…, Level Dialogue…), a More menu (Silence…, Invert Phase, Remove DC Offset, Swap Left and Right, Split to Mono Files…), the Plugins drawer, Save and Save As. A selection shows its length over the waveform, with Cut, Trim, the fades, Gain −1 and +1 dB and Analyse beside it. Operations that take values open a small popover. Edit works on one file: it is unavailable in a Compare session of two or more files, and going from Edit to Compare asks first about unsaved edits and an unrendered plugin chain.
2 · Apply an operation
Each operation runs on the selection, or on the whole file without one. Trim crops to the selection (⌘T); Cut (⌫) removes it and joins the sides with an equal-power crossfade, for a too-long pause or a flubbed line. Silence inserts at the playhead with no selection (say 500 ms for a video sync), or before, after or in place of a selection, in seconds or samples. Gain applies a gain in dB (⌥↑ and ⌥↓ for ±1 dB). Invert Phase flips the polarity. The fades offer linear, logarithmic and equal-power curves. Normalize targets a peak in dBFS or a loudness in LUFS with a ceiling, and its panel shows Now, Target and Gain for the selection or the whole file, whichever it applies to; LUFS normalizing that raises the level runs a 4× oversampled true-peak limiter. Limit True Peak caps the inter-sample peaks at a dBTP ceiling on its own. Level Dialogue ducks the room tone between speech regions and can lift the dialogue to a target in one pass (below). Remove DC Offset subtracts each channel's mean, Swap Left and Right swaps a stereo file's channels, and Split to Mono Files writes one mono WAV per channel. The delivery card's fixes open the same panels, filled in: Normalize to −14 LUFS with the target and its basis (integrated or dialogue-gated), Limit peaks to −1.0 dBTP with the target's ceiling, −3.1 dBTP for ACX.
3 · Undo, or save
History in the sidebar lists every edit by name, up to 16 steps back. A click on a step goes back or forward to it in one move, ⌘Z and ⇧⌘Z step one at a time, and the step that matches the file on disk says On disk. After every edit, Undo or Redo the file is measured again in the background, so the delivery card and the readings describe the audio in front. Save As (⇧⌘S) writes a new file at the source's bit depth and sample rate, and asks first when an integer file would clip samples above full scale, offering 32-bit float. With the setting on, Save (⌘S) writes over the open WAV, AIFF or CAF after asking; a failed write leaves the original untouched. Only the audio is rewritten: BWF, iXML, cue and marker chunks are not carried over. File › Export… can write the edited audio beside the reports.

The ceiling is a true-peak ceiling

A peak normalize that only watches sample values watches the wrong ceiling. The number that gets a master rejected, and the one streaming platforms enforce, is the inter-sample peak: the level the signal reaches once the converter reconstructs the waveform between samples. A file can read −1.0 dBFS on the samples and still overshoot when it is played back.

Specula's limiter measures the 4× oversampled inter-sample peak and holds the ceiling against that, in dBTP. Normalizing in LUFS runs it whenever the gain raises the level, in two offline passes: the first builds the gain envelope from the oversampled peaks, the second catches any peak the release left fractionally over the ceiling.

Limit True Peak is the same limiter on its own, with no loudness measurement and no gain stage: for a file whose loudness is right and whose inter-sample peaks need capping under a platform's ceiling.

Edit with the keyboard

The Edit task has its own keys, active only there so they never shadow the transport, listed in the Edit menu and in Help › Keyboard Shortcuts. One group acts on the selection, the other at the playhead.

⌫Cut: remove the selection and crossfade-join the sides.
⌥⌫Silence the selection (replace it, keep the length).
⌘TTrim to the selection (keep it, discard the rest).
⌘F / ⌥⌘FFade In / Fade Out on the selection.
⌥↑ / ⌥↓Gain +1 / −1 dB.
⌘⌫ / ⇧⌘⌫Cut to start / Cut to end, from the playhead.
⌥[ / ⌥]Fade in to / out from the playhead.
⌘Z / ⇧⌘ZUndo / Redo, one step of the history.
⇧⌘S / ⌘SSave As a new file / Save over the original, once allowed.

Level the dialogue without raising the floor

Level Dialogue is the edit for spoken word. It is a downward expander keyed to the speech regions Specula detects and the Speech task corrects: it ducks the room tone between phrases with a fast attack and a slow release, so word onsets and tails stay clean.

With Lift dialogue to a target on, it also brings the speech to a loudness target in the same pass, capping inter-sample peaks at a true-peak ceiling. The silence is gated first and the makeup gain goes on after, so the noise floor ends up lower, not higher, which is what makes it the fix for a room-tone floor sitting just over ACX's line.

It is a gate, not a denoiser. It rescues a marginal floor, not a hissy recording. Its main home is the Speech task's sidebar, where the Level dialogue panel predicts the dialogue loudness and the floor before Apply; the Edit task's Loudness menu opens the same edit. Your Audio Unit effects, right here

The Edit task hosts a chain of Audio Unit effects. The Plugins drawer adds any effect installed on the Mac (AUv2 and AUv3), chains several in order, bypasses or reorders them, and opens each plugin's own window, or a generic parameter panel for a plugin that ships none. It works on mono and stereo files, and the Edit menu reaches every drawer action.

The chain plays live while the file plays. Loudness details' Live side and the spectrum and phase panels follow the processed sound, while the delivery card and the whole-file readings keep describing the file until the chain is rendered.

Render bakes the chain into the audio through fresh, latency-compensated instances, as an edit in the history, and the file is measured again. With the effect tail off (the default) the rendered audio is exactly as long as the input, so it still lines up for an A/B and Align. Rendering clears the chain and remembers it, so Undo then Edit › Restore Last Plugin Chain is the tweak-again loop, and it survives quitting. Render to Compare Slot puts the processed version beside the original in Compare. AUv3 plugins run in their own process by default (Settings › Editing and plugins › Prefer out-of-process Audio Units), so a crash in one of them cannot take Specula down; AUv2 plugins run inside the app.

Blemishes come out on the spectrogram

Spectral (⌘6) is for the blemish inside the audio worth keeping: a cough inside a piano chord, a chair squeak under speech, a bite of mains hum. Select it on a full-resolution, zoomable spectrogram, in time and frequency, then attenuate, erase or repair just that region, leaving the rest bit for bit. Include harmonics adds the overtones of a squeak or a whistle to the selection. It is a bigger job than the trims and fades on this page, so it has its own workflow: the selection tools, the wand's tolerance and reach, the feather, Include harmonics, and auditions before Apply.
